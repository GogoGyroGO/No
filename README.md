## Gyro’s Spin — Minecraft 1.20.1 Fabric

[Скачать готовый мод](dist/gyro-spin-1.0.0.jar?raw=true) · [Установка, способности и рецепты](MOD_GUIDE.md)

Нужны Java 17, Fabric Loader 0.15.11+ и Fabric API 0.92.2+1.20.1. Положите JAR мода и Fabric API в папку `mods`.

Стальные шары Джайро, пять ступеней Spin, дерево навыков за опыт, наставник Джайро и секретная коляска.

Проверено: сборка, 5 модульных тестов и 4 серверных GameTest. Визуальная проверка клиента ещё не проведена.
